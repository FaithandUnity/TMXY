# Table XML, CLSVShare XML, and ClassCfg inventory

P2-05 inventories the non-TBL configuration population in the frozen
`qy-3.0.0.413` client sandbox. The machine-readable result is
`Data/Inventory/p2-05-auxiliary-config-inventory.json`; it is regenerated by
`Tools/TMXY.Table/New-AuxiliaryConfigInventory.ps1`.

## Frozen population

The inventory covers all 212 files and 1,909,135 bytes in scope:

- 136 `Table/Regions` XML files;
- one `Table/help_docs.xml` fragment;
- 11 `CLSVShare` XML files;
- 64 `ClassCfg` ECF files.

Every entry records the relative path, source size, SHA-256, timestamp,
encoding, structural classification, and ownership classification. No input is
copied into the repository.

## XML findings

All 148 XML inputs require strict GBK decoding. After decoding, 138 are strict
XML documents and four are valid XML fragments. Six files are not accepted by
either a secure document or fragment reader and are isolated with stable error
categories:

- `CLSVShare/box_item.xml`;
- `CLSVShare/default_charinfo.xml`;
- `CLSVShare/guildglobals.xml`;
- `CLSVShare/Professions.xml`;
- `CLSVShare/westsky.xml`;
- `Table/Regions/world.xml`.

The parser prohibits DTD processing and external resolution. Malformed inputs
remain raw evidence for an explicit compatibility parser test in P2-06; the
inventory does not silently repair them.

## ECF findings

All 64 ECF files decode with the same self-inverse transform: within every
four-byte group the two halves are exchanged and every byte is inverted; tail
bytes are inverted. All 64 decode/encode round trips reproduce their source
bytes exactly. The decoded shape is line-oriented key/value configuration:
2,415 physical lines and 2,065 assignment lines. Sixty-one payloads are ASCII
and three require GBK.

The evidence stores only counts and classifications. It emits no decoded line,
assignment key, assignment value, XML text, or XML attribute value. Three ECF
files contain nine repeated assignments in total; these are override facts for
later schema work, not permission to choose a winning value automatically.

## Ownership and duplicate boundaries

The 11 `CLSVShare` XML files are shared configuration data. A complete scan of
1,972 legacy server source files finds literal references for nine, while the
current client configuration references seven; their union covers all 11.

The other 201 files are client-only: 130 direct region files, six nested exact
region shadows, one help fragment, and 64 ECF configurations. The region loader
constructs `Table/Regions/<world>.xml`, while the legacy QRender solution points
to a ClassCfg project that is absent from the supplied source snapshot.

There are 14 exact-content duplicate groups covering 30 files. Six groups are
same-basename nested region shadows, and eight reuse identical content under
different logical names. No same-basename divergent override candidate exists.
No duplicate is deleted by P2-05.
