# ADR-003：遗留坐标与 UE 单一边界转换

- 状态：Accepted
- 日期：2026-08-26
- 实施：`Tools/TMXY.Transform`

## 决策

遗留运行时空间与 UE 5.8.2 都使用 X 前、Y 右、Z 上的左手坐标语义。已序列化的遗留资源进入 UE 时不交换轴；位置从米乘以 100 转为厘米；方向分量不缩放；旧角度单位按一圈 65,536 转为度，并执行 `Pitch=-P`、`Yaw=Y`、`Roll=-R`。

遗留矩阵和 UE 矩阵都按行向量仿射约定解释，平移位于第 3 行，转换时只放大平移。已序列化 UV 已在 Max 导出边界执行 `V=1-V`，因此到 UE 保持 `(U,V)`；已序列化三角形绕序同样保持。若下游把负行列式矩阵烘焙进顶点，则必须恰好反转一次绕序；退化基底必须报错。

所有导入器必须调用 `LegacyToUETransform`，不得复制坐标、角度、UV 或绕序换算。第一层解析与规范化中间模型继续保留原始值，转换只发生在 UE-facing 输出边界。

## 原因

旧 `QRotator`、`QMatrix`、Max 导出器和 UE 5.8.2 `TRotationTranslationMatrix` 可以形成相互独立的代码证据。角色碰撞高度约 0.7～2.0、移动速度约 4～5，且物理重力为 9.8，证明遗留空间单位为米。集中转换可以防止网格、骨骼、动画、场景和导航各自形成略有不同的约定。

## 后果

- 旧位置 `1.0` 对应 UE `100.0 cm`。
- 旧方向、法线轴和已序列化 UV 不发生轴交换或 V 二次翻转。
- 旧欧拉角不能直接赋给 `FRotator`；必须使用冻结的符号和单位换算。
- 任意 NaN、Infinity、零长度法线、投影矩阵或退化烘焙基底都会产生稳定错误。
- 若后续真实样本反证本决策，必须新增 ADR 修订与全量黄金回归，不能在单个导入器中打补丁。
