# TMXY.ConversionRouting

P2-15 converts P2-14 health evidence into one route, tier, priority, duplicate
handling decision, and planning estimate for every asset. Estimates are declared
coefficients for P2-19 planning, not measured throughput or schedule promises.

Exact-byte aliases are reusable only for independently parsed, structurally valid
MP3/SM/SKEM/TER/WAV/ZIF files. Headerless QTX and ANIM remain review-only because
identical source bytes do not prove identical external descriptors. Every source
path alias is preserved and no route authorizes deletion or repair.

```powershell
.\Tools\TMXY.ConversionRouting\New-ConversionRouting.ps1
.\Tools\TMXY.ConversionRouting\New-ConversionRouting.ps1 -Check
.\Tools\TMXY.ConversionRouting\Find-ConversionRoute.ps1 -Priority P0-first-playable-slice
```

The per-asset report stays in ignored `Data/Exports/P2-15`; Git tracks aggregate
evidence and the reproducible policy, generator, query tool, tests, and docs.
