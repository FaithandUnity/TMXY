# 项目版权与授权基线

> 记录日期：2026-08-26  
> 记录性质：项目负责人的权利声明，用于确定重构工作的工程范围；不替代发布前的正式法律文件归档。

## 项目负责人声明

项目负责人已明确确认：其对本项目范围内的老源码、当前客户端内容及相关美术资源拥有完整版权，可以用于本项目的内部研究、修改、技术重构和后续发布。

因此，本项目可以将以下工作纳入正式实施范围：

- 分析并重构现有客户端与服务端源码；
- 解析、转换和导入当前客户端中的运行时美术资源；
- 将资源转换为 UE 5.8.2 可维护资产；
- 修改、升级并发布新的客户端与服务端实现；
- 建立 Package、TBL、资源、协议和数据迁移工具链。

## 仍需单独管理的事项

项目资产权利确认不自动改变第三方组件自身的许可证。发布前仍需建立第三方清单并核查：

- ACE、Lua、TinyXML、Protobuf 等第三方源码或库；
- 字体、音频编码器、数据库驱动和其他中间件；
- Unreal Engine 及相关 Marketplace/插件的许可和分发条件；
- 后续新增依赖、外包内容和采购资产。

第三方许可证审计属于 P0 构建依赖盘点及 P8 发布复核的一部分，不阻碍当前内部技术重构。
