# TMXY.G2AuxSemanticDiagnostics

P2-20A.5 independently replays the frozen auxiliary population through the
observed legacy consumer boundary. It measures region-field reference semantics
and ECF parser parity without approving an adapter, a no-reference disposition,
a traversal root, G2, P3, or release.

Every one of the 212 source instances is byte-count and SHA-256 checked before
classification. Consumer source bodies are accepted only as unique digest
matches inside the read-only legacy client source root.

The generator and its support module implement the deterministic scan; the
PowerShell wrapper owns tracked generation and reproducibility checks.

Run from PowerShell:

```powershell
.\Tools\TMXY.G2AuxSemanticDiagnostics\New-G2AuxSemanticDiagnostics.ps1
.\Tools\TMXY.G2AuxSemanticDiagnostics\New-G2AuxSemanticDiagnostics.ps1 -Check
.\Tests\Contract\Test-G2AuxSemanticDiagnostics.ps1 -VerifyDerivedSources
```

The repository and legacy source tree are mounted read-only in the locked,
non-root builder with no network or Linux capabilities. Tracked outputs contain
only aggregate counts, role labels, hashes, and reason codes.
